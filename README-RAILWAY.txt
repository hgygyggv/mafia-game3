راهنمای استقرار بازی مافیا روی Railway

1) همه فایل‌های این پوشه را در ریشه یک مخزن GitHub قرار بده.
2) در Railway گزینه New Project / Deploy from GitHub Repo را انتخاب و همین مخزن را وصل کن.
3) در Variables این متغیرها را تنظیم کن:
   ADMIN_PASS = یک رمز قوی و اختصاصی (رمز پیش‌فرض داخل کد را استفاده نکن)
   DATA_FILE = /data/data.json
4) در Settings سرویس، یک Volume بساز و آن را روی مسیر /data متصل کن تا اطلاعات کاربران با استقرار مجدد پاک نشود.
5) Railway به‌صورت خودکار دستور npm start را اجرا می‌کند.
6) پس از Deploy، دامنه عمومی بساز (Generate Domain). همان دامنه https://... را برای بازیکنان بفرست.
   سرور به‌صورت خودکار WebSocket امن wss را از همان دامنه مدیریت می‌کند.

نکته:
- سرور اصلی موجود حفظ شده و پکیج خارجی اضافه نشده است.
- پورت از متغیر PORT محیط Railway خوانده می‌شود.
- فایل HTML به index.html تغییر نام داده شده تا سرور آن را قطعی پیدا کند.
- بدون Volume و DATA_FILE پایدار، فایل data.json ممکن است با حذف/تعویض کانتینر از دست برود.
- فایل‌های محرمانه و data.json را در GitHub بارگذاری نکن.
