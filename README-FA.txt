# بازی آنلاین مافیا

## فایل‌ها
- `index.html`: صفحه بازی
- `server.js`: سرور Node.js
- `package.json`: دستور اجرای سرور

## اجرا
در محیط میزبان، دستور شروع را روی `npm start` قرار دهید.

سرور از متغیر محیطی `PORT` استفاده می‌کند. فایل `data.json` در کنار سرور ساخته می‌شود؛ برای نگهداری دائمی اطلاعات، دیسک پایدار یا دیتابیس دائمی میزبان را تنظیم کنید.

**نکته:** فایل `data.json` را در GitHub بارگذاری نکنید و اگر از قبل در مخزن وجود دارد، بدون تهیه نسخه پشتیبان حذفش نکنید.
